# Vie privée

Stomo ne demande aucun compte et n’envoie pas les films sur un serveur.

- La caméra sert uniquement à fabriquer les photos demandées dans le studio.
- Les projets, photos et vignettes sont conservés dans le stockage du
  navigateur sur le téléphone.
- Les exports sont préparés sur l’appareil puis enregistrés ou partagés à la
  demande.
- Stomo n’utilise ni publicité, ni analyse d’audience, ni suivi d’usage.
- Le journal de session enfant reste lui aussi sur l’appareil.

GitHub Pages distribue les fichiers de l’application. Comme pour toute page
hébergée sur GitHub, la requête de téléchargement initiale est traitée par
GitHub. Une fois l’application installée et mise en cache, ses fonctions de
création ne nécessitent aucun service distant.

Effacer les données du site dans le navigateur supprime les projets locaux.
Utiliser **Garder mon projet** avant une suppression ou un changement de
téléphone.
